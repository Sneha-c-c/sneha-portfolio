# sneha-portfolio

Sneha CC — Full Stack Software Engineer portfolio.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React
- Deployed on Vercel

## Getting started

Requires **Node.js 22**.

```bash
nvm use 22
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — start production server
- `npm run lint` — ESLint

## Contact form

By default, the contact form opens the visitor’s email client (`mailto:`).

To use Formspree, set:

```bash
NEXT_PUBLIC_FORMSPREE_ID=your_form_id
```

## Content

Resume-backed content lives in `data/`. Update those files to change profile, skills, experience, and projects.
